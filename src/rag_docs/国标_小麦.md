# GB 1351-2023 小麦质量标准

## 质量分级

### 一等
- 容重 ≥ 790 g/L
- 不完善粒 ≤ 6.0%
- 水分 ≤ 12.5%
- 杂质总量 ≤ 1.0%
- 矿物质 ≤ 0.5%
- 色泽气味：正常

### 二等
- 容重 ≥ 770 g/L
- 不完善粒 ≤ 6.0%
- 水分 ≤ 12.5%
- 杂质总量 ≤ 1.0%
- 矿物质 ≤ 0.5%
- 色泽气味：正常

### 三等
- 容重 ≥ 750 g/L
- 不完善粒 ≤ 8.0%
- 水分 ≤ 12.5%
- 杂质总量 ≤ 2.0%
- 矿物质 ≤ 1.0%
- 色泽气味：正常

## 储存要求
- 安全水分：≤ 12.5%
- 粮温正常范围：-10°C ~ 30°C
- 粮温日升速率 > 1°C 为异常
