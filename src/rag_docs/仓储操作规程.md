# 粮库仓储操作规程

## 通风作业规则
- 粮温 > 目标温度 +5°C 且室外温湿度适宜 → 建议机械通风
- 仓内湿度 > 75% 且室外湿度 < 65% → 建议通风排湿
- 粮温分层明显（温差 > 3°C）→ 建议通风均温
- 夏季高温高湿 → 不建议通风，建议空调控温

## 熏蒸作业规则
- 虫害密度 > 10 头/kg → 需立即熏蒸
- 虫害密度 5~10 头/kg 且呈上升趋势 → 建议安排熏蒸
- 虫害密度 < 5 头/kg → 暂不需要熏蒸
- 熏蒸前必须检查仓房气密性
- 熏蒸后需通风散气 ≥ 72 小时

## 设备操作规范
- 设备操作前必须检查设备状态（online/offline）
- 启动风机前确认仓窗已开启
- 设备故障时自动切换备用设备
- 每季度至少进行一次设备维护保养

## 异常处理
- 粮温 > 35°C → 立即启动应急通风或空调降温
- CO₂ > 1000ppm → 提示粮食可能发热，需排查
- 发现霉变 → 立即隔离该仓粮食，取样检测真菌毒素
