# GB 1350-2023 稻谷质量标准

## 质量分级

### 一等
- 出糙率 ≥ 79.0%
- 整精米率 ≥ 50.0%
- 水分 ≤ 13.5%
- 杂质总量 ≤ 1.0%
- 黄粒米 ≤ 0.5%
- 色泽气味：正常

### 二等
- 出糙率 ≥ 77.0%
- 整精米率 ≥ 47.0%
- 水分 ≤ 13.5%
- 杂质总量 ≤ 1.0%
- 黄粒米 ≤ 0.5%
- 色泽气味：正常

### 三等
- 出糙率 ≥ 75.0%
- 整精米率 ≥ 44.0%
- 水分 ≤ 13.5%
- 杂质总量 ≤ 2.0%
- 黄粒米 ≤ 1.0%
- 色泽气味：正常

## 储存要求
- 安全水分：≤ 13.5%
- 仓内湿度建议：40%~70%RH
