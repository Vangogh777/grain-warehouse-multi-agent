二、Agent 辩论/投票机制 P2

2.1 目标

多个 Agent 对同一问题独立分析，然后聚合投票得出最终结论。类似「专家会诊」模式。

对比当前（单 Agent 回答）辩论模式
粮情分析✅ 参与✅ 独立分析 + 投票
智能作业❌ 不参与✅ 独立分析 + 投票
质量检测❌ 不参与✅ 独立分析 + 投票
结论单 Agent 说了算多 Agent 投票决定

2.2 流程设计

用户：S-07 是否需要通风？

步骤 1 ── 并行分发 ──────────────────────┐
  ├── 粮情分析：分析温湿度数据 → 结论 + 置信度
  ├── 智能作业：分析天气/设备 → 结论 + 置信度
  ├── 质量检测：分析粮食品质 → 结论 + 置信度
  └── 报表分析：分析历史趋势 → 结论 + 置信度

步骤 2 ── 投票聚合 ──────────────────────┐
  聚合 Agent 读取 4 个 Agent 的结论和置信度
  → 加权投票：结论 A (3票) vs 结论 B (1票)
  → 输出最终结论 + 分歧说明

2.3 数据结构

// 每个 Agent 返回结构化投票数据
{
  "agent": "粮情分析",
  "conclusion": "建议通风",
  "confidence": 0.85,      // 置信度 0~1
  "reason": "上层温度32°C偏高",
  "evidence": ["温度", "湿度"],
}

// 聚合结果
{
  "winner": "建议通风",
  "votes": {"建议通风": 3, "暂不通风": 1},
  "confidence": 0.75,
  "dissenting": ["质量检测不通风理由：水分接近阈值"]
}

2.4 实现步骤

  1. 知识库：在 DebateInput schema 定义投票数据结构
  2. 编排器：新增 debate(query) → 并行调所有 Agent → 投票聚合
  3. 聚合 Agent：用一个专用 Agent 读取各 Agent 的结构化结论，加权投票
  4. 前端：新增「🤝 多 Agent 辩论」按钮，展示投票柱状图

2.5 核心代码

# orchestrator/debate.py
class DebateOrchestrator:
    async def debate(self, query: str) -> dict:
        # 1. 并行调所有 Agent
        tasks = [agent.run(query + "\n请输出结构化结论") for agent in self.agents.values()]
        results = await asyncio.gather(*tasks)
        
        # 2. 解析结构化结论
        votes = {}
        for r in results:
            conclusion = parse_conclusion(r["output"])
            votes[conclusion["option"]] = votes.get(conclusion["option"], 0) + conclusion["confidence"]
        
        # 3. 统计投票
        winner = max(votes, key=votes.get)
        return {
            "winner": winner,
            "votes": votes,
            "details": results,
        }
